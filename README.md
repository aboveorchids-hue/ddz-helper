# 鬥地主小助手

神來也鬥地主的出牌建議小幫手。用 iPad（iPadOS 27 的 Safari）打開網頁、分享螢幕，輪到你時自動讀牌桌並在畫面上顯示建議。

網址：https://aboveorchids-hue.github.io/ddz-helper/

## 怎麼用
1. 遊戲和 Safari 分割畫面（或台前調度兩個視窗並排），遊戲視窗要完整露出來。
2. 按「開始讀螢幕」，選擇分享螢幕。
3. 輪到你時，建議會自動出現；開新的一局時按「新的一局」。

## 隱私
螢幕畫面只在你的 iPad 上辨識，不會上傳到任何地方。

## 內容
- `vision.js` 讀牌桌，`tracker.js` 追蹤牌局，`engine.js` 出牌 AI（DouZero 模型移植），`endgame.js` 任務與殘局計算。
- 出問題時，展開「紀錄」按「複製紀錄」，必要時按「存下目前畫面」。
